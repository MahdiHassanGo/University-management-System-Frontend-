# University Management System (UMS) - Frontend

An enterprise-grade, modern, and accessible University Management System built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **shadcn/ui**, **TanStack Query v5**, **TanStack React Form**, and **Zod**.

Designed for three primary institutional roles:
- 🎓 **Super Admin**: Institutional governance, academic catalog management, student & instructor administration, enrollments, reports & analytics.
- 👨‍🏫 **Instructor**: Section management, student rosters, session attendance tracking, exams & grading, and result publication.
- 🧑‍🎓 **Student**: Academic dashboard, course enrollment, class schedule, attendance monitoring, published grades, unofficial transcripts, and fee payment via SSLCommerz test gateway.

---

## 🚀 Tech Stack & Architecture

- **Framework**: Next.js 16 App Router & React 19
- **Styling**: Tailwind CSS v4 & custom academic design system tokens
- **UI Components**: shadcn/ui & Lucide React
- **Data Fetching & Caching**: TanStack Query v5 with optimistic updates
- **Forms & Validation**: TanStack React Form & Zod
- **API Client**: ofetch with auto credentials & bearer token interceptor
- **Client State**: Zustand
- **Visualizations**: Recharts
- **Linter & Formatter**: Biome
- **Package Manager & Runtime**: Bun

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/MahdiHassanGo/University-management-System-Frontend-.git

# Install dependencies
bun install

# Run the development server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
